Adaptive CH Selection Metric Formula

Each sensor node calculates an objective score combining normalized residual battery energy ($E_{res}$) and distance suitability to the Base Station ($d_{BS}$):

Score_i = w_E · (E_res,i / E_max) + (1 - w_E) · (1 - d_i,BS / d_max)

Where $w_E = 0.6$. The top $k$ nodes with the highest scores assume Cluster Head duties, collecting, compressing, and encoding telemetry packets before forwarding them over the long-distance uplink to the Base Station.

Why Low-Density Parity-Check?
Sparse parity check matrices have very few 1s per row and column. This allows iterative graph-based belief propagation decoders to resolve bit ambiguities through linear-complexity local message updates.

Mathematical Formulation of BPSK

In Binary Phase Shift Keying, the modulated bandpass signal is expressed as:

s_k(t) = A · cos(2π·fc·t + (1 - b_k)π), 0 ≤ t ≤ T_b

Equivalently, using baseband antipodal symbol notation:
• If bit $b_k = 0 \implies s_k = +A$ (in-phase carrier $\cos(2\pi f_c t)$)
• If bit $b_k = 1 \implies s_k = -A$ (inverted carrier $\cos(2\pi f_c t + \pi)$)

Power Efficiency
BPSK yields the lowest theoretical bit error rate among all binary modulation schemes for a given signal-to-noise ratio: $P_b = Q(√(2Eb/N0))$.

Mathematical Noise & Fading Model

The continuous-time and discrete sample representations of the received signal are:

r(t) = h(t) · s(t) + n(t)

• AWGN: $n(t) \sim \mathcal{N}(0, \sigma^2)$, generated via the Box-Muller transform:
$\sigma = \sqrt{\frac{E_s}{2 \cdot 10^{\text{SNR}_{dB}/10}}}$.
• Rayleigh Fading: $h = \sqrt{x^2 + y^2}$ with zero-mean Gaussian quadrature components representing multipath scattering in dense urban buildings.
• Rician Fading: Direct Line-of-Sight path with $K$-factor dominant specular component.

Channel Impairment Impact
At negative or low SNR (e.g. $\le 2\text{ dB}$), noise frequently causes received symbol samples to cross the zero threshold into the opposite decision region, generating bit errors that require LDPC correction.

Decision Rule Analysis
If $y_k \ge 0$, the receiver decides bit $0$. If $y_k < 0$, it decides bit $1$. When severe noise pushes a $+1$ symbol below zero (or a $-1$ symbol above zero), a raw detection error occurs (highlighted in flashing red). These errors are passed to the LDPC decoder for correction.

Engineering Knowledge Base & Technical Glossary

This laboratory demonstrates an energy-efficient digital communication architecture designed for smart city IoT deployments. Key concepts and system definitions are outlined below:

1. ESP32 Microcontroller
Dual-core 32-bit Xtensa microcontroller with integrated 2.4GHz Wi-Fi and Bluetooth. Used in smart cities for sensor data acquisition and edge preprocessing.
2. Wireless Sensor Network (WSN)
Spatially dispersed autonomous IoT sensors monitoring physical and environmental conditions such as air quality, traffic, and water levels.
3. Adaptive Clustering
Autonomous organization of sensor nodes into local groups to limit long-distance transmissions and distribute transceiver battery depletion.
4. Cluster Head (CH)
Elected high-energy coordinator node responsible for collecting local sensor measurements, aggregating packets, and transmitting over the uplink to the Base Station.
5. Base Station (Sink)
Central data gateway and municipal processing server receiving telemetry from all Cluster Heads for smart city dashboard analytics.
6. LDPC Error-Correction
Low-Density Parity-Check block codes invented by Robert Gallager, achieving near-Shannon-limit channel capacity via iterative sparse graph decoding.
7. Parity-Check Matrix (H)
Binary matrix defining parity constraints. For valid codeword $c$, $H \cdot c^T = 0 \pmod 2$. In systematic form $H = [P \mid I_m]$.
8. BPSK Modulation
Binary Phase Shift Keying. Digital modulation shifting carrier phase by $180^\circ$ ($\pi$ radians) between bit 0 ($+A$) and bit 1 ($-A$).
9. AWGN Channel
Additive White Gaussian Noise. Thermal noise with uniform spectral density across all frequencies and Gaussian distribution in the time domain.
10. Signal-to-Noise Ratio (SNR)
Ratio of signal power to background noise power: $\text{SNR}_{dB} = 10 \log_{10}(P_{signal} / P_{noise})$. Key determinant of link quality.
11. Bit Error Rate (BER)
Ratio of incorrectly received bits to total transmitted bits: $\text{BER} = N_{err} / N_{total}$. Raw channel BER is reduced to zero by LDPC.
12. Coherent Demodulation
Receiver technique correlating the noisy signal against an in-phase reference carrier $\cos(2\pi f_c t)$ and thresholding at $\gamma = 0$.
13. Channel Fading (Rayleigh/Rician)
Rapid fluctuations in signal amplitude caused by multipath constructive and destructive interference from buildings, vehicles, and terrain.
14. Belief Propagation (Sum-Product)
Iterative message-passing algorithm operating on Tanner graphs that exchanges probability vectors or LLRs between variable and check nodes.
15. Energy Efficiency Model
First-order radio energy formulation modeling transmit electronics dissipation ($E_{elec}$) and path loss ($d^2$ free space, $d^4$ multipath).
